# 🏛️ Módulo 07 — Introdução ao Protheus e ADVPL

Este diretório reúne os exercícios e anotações desenvolvidos durante o **Módulo 07** da **Jornada DEV START (TOTVS Paulista)**.

Neste módulo iniciamos os estudos sobre o **ERP TOTVS Protheus**, compreendendo sua arquitetura, funcionamento interno, principais tabelas e os primeiros conceitos da linguagem **ADVPL**.

---

## 🎯 Objetivos

- Entender a arquitetura do Protheus
- Conhecer as principais tabelas do sistema
- Aprender o funcionamento do Dicionário de Dados
- Estudar os principais comandos ADVPL
- Compreender a navegação em tabelas DBF
